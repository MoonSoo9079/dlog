Hosts

Agents that hold this server's certificate register themselves. The hostname is how an agent is recognized and stays put. A display name is what the log list shows. Put a host in one group, or disable a host to stop it.

Settings

Branding, registration, the agent certificate, and how long logs and sessions are kept. Groups and accounts are here too.

Branding

The name is shown in the header and on the sign-in page. Leave it blank to use Dlog. The tagline replaces the sentence under the name on the sign-in page.

Logs and sessions

Lines older than the retention window are deleted about once a minute. Keep logs stores them until you delete a host. A session stays signed in while the browser is in use, and each request extends it. A host looks offline when nothing has been heard for the offline window. Agents send a heartbeat every 15 seconds.

Registration

Automatic registration creates a host when an agent signs in with this server's certificate. Turn it off and new hostnames wait for approval. An agent that already registered keeps its token and can register again. A new host joins the default group, or stays ungrouped.

Waiting for approval

These agents signed a registration while automatic registration was off. Approve creates the host. The agent receives a token the next time it registers. Dismiss drops the request.

Certificate

Every agent uses this certificate to register. Replacing it stops registration until each agent has the new certificate and key. Hosts that already have a token keep sending logs.

Groups

A group is a folder in the log list. A host is in one group. Deleting a group leaves its hosts ungrouped. A name starts with a letter or digit and may use letters, digits, spaces, ., _, and -.

Accounts

Users can read logs. Admins can also manage hosts, groups, and accounts. A user sees every host, or only the groups you tick. Hosts with no group stay visible to admins and to users who can see all hosts. A username starts with a letter or digit and may use letters, digits, ., _, and -. A password is 8 to 72 characters. Setting a password signs that account out.
